How I work

From raw files to a clear answer

The same four steps sit behind every project, whatever the tool.

  1. help 01

    Ask

    Pin down the business question and the KPIs that answer it, before touching the data.

  2. cleaning_services 02

    Clean

    Import, fix and reshape messy CSVs and reports with Power Query and SQL.

  3. hub 03

    Model

    Link tables into a star schema and write DAX measures for revenue, orders and trends.

  4. insights 04

    Communicate

    Build dashboards with slicers and drill-downs that a non-technical audience can read at a glance.
